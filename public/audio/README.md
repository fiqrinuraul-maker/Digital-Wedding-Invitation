# Background Music Directory

Put your wedding invitation background music (.mp3 format) here!

Filename: `wedding-bgm.mp3`
Path: `public/audio/wedding-bgm.mp3`

Supported formats: `.mp3`, `.m4a`, `.wav`

If you change the filename, update `src/config/weddingConfig.js`:
```js
audio: {
  src: "/audio/wedding-bgm.mp3"
}
```
